# Tier rubric

What each assistance tier may and may not contain. Both the rules and the LLM prompts depend on this.

| Tier | May contain | Must not contain |
| --- | --- | --- |
| Human First | Encouragement, restating the task, a reminder of past success | Any approach, hint or solution |
| Hint | One nudge toward the next step | Steps, code, final answer |
| Guided | Step-by-step questions and partial structure | The complete solution |
| Shared | Joint plan; AI drafts parts the user reviews | Taking over the user's decisions |
| Emergency | Full solution with explanation | - |
